# Referències De Disseny Stitch

## Propòsit

Aquest document centralitza les pantalles Stitch aprovades com a referències
adaptables per a la web. No pertanyen a una fase concreta: una mateixa pantalla
pot informar components i rutes implementats en fases diferents.

## Jerarquia De Fonts

`DESIGN.md` és la font de veritat de la direcció visual i preval sobre qualsevol
pantalla o sistema de Stitch. Mountain Runners és light-first: els fons blancs o
blancs càlids predominen fora de moments editorials deliberats de contrast.

Les pantalles Stitch orienten la composició, la jerarquia i els estats visuals,
però no substitueixen els requisits d'accessibilitat, responsive, dades
editorials ni contingut aprovat. Les dades de mostra que hi apareguin no es
consideren contingut publicable.

## Projecte I Sistema Visual

Projecte Stitch: [Redisseny Mountain Runners Berga](https://stitch.withgoogle.com/projects/6497516597197145737)
(`6497516597197145737`).

El sistema visual registrat per a les referències aprovades és
`assets/15875972618739072807`, _Associacio Esportiva Mountain Runners_. Una
instància de Stitch amb direcció dark-first no és una referència aprovada i no
pot substituir `DESIGN.md` sense una decisió explícita.

## Actualització De Referències

- Una pantalla modificada substitueix l'anterior només després de la seva
  aprovació explícita; el seu registre s'actualitza amb l'ID, l'enllaç i la data
  nous.
- Una pantalla oculta o substituïda deixa de ser una referència vigent i no es
  manté com a font d'implementació.
- Una fase o PR que necessiti evidència visual enllaça aquesta pàgina i identifica
  només les pantalles que utilitza; no n'ha de duplicar la taula.
- Un canvi que contradigui `DESIGN.md` requereix revisar primer la direcció de
  disseny; no s'accepta implícitament en actualitzar un ID de Stitch.
