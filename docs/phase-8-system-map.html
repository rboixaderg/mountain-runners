Components i fronteres

El pont rep la petició de Telegram i la passa al flux de treball. Pi consulta el model; les ordres sobre la còpia de treball s'executen al sandbox. El servei de confiança gestiona GitHub.

On és el codi

Components de l'agent i directori on viuen
Component Ubicació Responsabilitat
Pont packages/telegram-pi-bridge/ Telegram, autorització, cua SQLite i protocol RPC de Pi
Punt d'unió tools/server/agent/processes/telegram-bridge/ Connecta el pont amb el flux de desenvolupament
Flux de treball tools/server/agent/workflow/, tools/server/agent/policy/ Coordina el torn, la CI, la preview i el merge; la política (prompts, comprovacions, noms) és codi pur
Runtime i sandbox tools/server/agent/runtime/, tools/server/agent/sandbox/ Perfil i entorn de Pi; contenidors Podman
Repositori tools/server/agent/repository/ Git de confiança, escaneig de secrets, publicació a GitHub i estat durador a state/agent.sqlite
Adjunts tools/server/agent/attachments/ Validació, reducció i magatzem de les imatges del tema
Cerca web tools/server/agent/web-research/ Brave i pàgines públiques, fora del sandbox
Ordres d'operador tools/server/agent/commands/ Reconciliació, actualització, migració de l'estat i revisió de recerca
